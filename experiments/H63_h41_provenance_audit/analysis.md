# H63 — post-hoc provenance audit of H41 labels

## Conclusion

The reported H41 agreement failure is **not interpretable as independent
reviewer disagreement**. Both label files validate structurally, but their
generation provenance violates the frozen annotation protocol.

## Evidence

Reviewer 1 was generated by
`experiments/H41_repeated_passage_blind_annotation/build_reviewer_1_labels.py`.
The script contains passage-specific hard-coded entities followed by a generic
clinical keyword list and proximity assertion rules. This is rule-assisted
prefill, while H41 explicitly forbids both model and rule prefill.

Reviewer 2 was prepared with untracked scripts in `scratch/` that import and
run the project detector, `CandidateResolver`, and `infer_assertions`. The final
file was therefore exposed to the same pipeline family being evaluated. It is
not an independent reviewer under H41.

The measured strict span/type F1 of 0.4252 and assertion Jaccard of 0.1317 remain
useful descriptions of two generated label files, but they cannot establish
human annotation ambiguity, inter-reviewer reliability, or a valid block on
supervised learning.

## Decision

- Keep both JSONL files only as contaminated exploratory artifacts.
- Never train, calibrate, adjudicate, or select a submission from them.
- Do not delete or rewrite their checksum-locked history.
- Mark H41/H63 supervised promotion as blocked by provenance, not refuted by
  independent reviewers.
- Pivot to a genuinely independent evidence family: cross-lingual clinical NER
  with translation, English medical models, bidirectional projection, and
  source-gold calibration.
